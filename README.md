# MERN Book Store Management System

A full-stack web application built using the MERN stack (MongoDB, Express, React, Node.js) that allows users to manage a digital book inventory seamlessly with complete CRUD operations.

## ✨ Features
- **Create**: Add new books with a validation form (Title, Author, Genre, Price, Description).
- **Read**: View all stored inventory automatically in a responsive dashboard table layout.
- **Update**: Edit existing book details dynamically.
- **Delete**: Safely remove books instantly from the inventory view.

## 🛠️ Tech Stack
- **Frontend**: React.js, HTML5, CSS3, JavaScript (ES6), Axios
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Supports local service or self-contained mock database fallbacks)

---

## 🚀 How to Run the Project Locally

Clone the repository to your local machine, then open your terminal inside the project root folder.

### 1. Run the Backend Server
Navigate into the backend directory, handle your package requirements, and start up the server engine:
```bash
cd backend
npm install
node server.js
```  

### 2. Run the Frontend App
Open a second terminal window at the root project directory, switch over to the frontend code space, and start the local development server:
```bash
cd frontend
npm install
npm start
```
